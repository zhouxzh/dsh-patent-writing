# 专利实验与证据

## 原则

申请可以先于产品完成，但效果论证必须有边界。设计公式、物理约束和预期效果可以写入交底；不得编造实测结果。

## 证据等级

- 设计计算；
- 器件手册和公开标准；
- 电路/工艺仿真；
- 台架测量；
- 完整样机对照。

## 核心实验

至少设计：

1. 现有方案基线；
2. 本发明关键结构的单独作用；
3. 完整组合；
4. 失败案例和超出适用范围；
5. 可量化指标及置信区间。

## 记录

每次实验保存设备、固件、原理图版本、校准文件、原始数据、脚本、环境、失败样本和结果摘要。

## 表述

没有测试时写作“预期效果”或“拟验证效果”。若只用理论推导，给出公式或明确性能边界，不写具体百分比。
