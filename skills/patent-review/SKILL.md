# 专利交底审查

## 先读对象

读取当前主稿、权利要求草案、附图源、效果依据、检索账本和实现状态。只审旧版本会导致误判。

## 七个维度

1. **技术方案**：问题、结构、步骤、控制关系是否闭环。
2. **形式**：标题、章节、图号、表格、字体、页面。
3. **可实施性**：本领域技术人员能否按交底复现；未实现设计是否写明。
4. **权利要求支持**：每个技术特征是否有说明书依据。
5. **效果**：是否有物理模型、公式、实验或明确证据等级。
6. **创造性**：最接近方案、区别特征和非显而易见性。
7. **公开状态**：私有仓库、送样、展会、论文和时间线。

## 问题级别

- `P0`：方案矛盾、硬件事实错误、核心环节不可实施，可能导致无法支撑主案。
- `P1`：权项或效果支撑不足，交代理前必须补。
- `P2`：形式、语言、命名和图号问题。

## 输出

先列 P0，再列 P1/P2，每条给出文件行号、问题、原因和具体修法。最后单独给：

- 是否可以交代理；
- 是否可以立即提交；
- 创造性判断的证据边界；
- 仍需补充的材料。

评分只能作为内部进度，不得表述为授权概率。
