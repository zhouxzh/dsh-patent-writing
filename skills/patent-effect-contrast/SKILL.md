# 有益效果对比

每项效果写成三段：

1. **现有技术如何**：指出具体方案、结构和失败条件。
2. **本方案如何**：对应到具体模块、步骤、参数或控制关系。
3. **因此产生什么差异**：给出范围、复杂度、稳定性、恢复时间或误差指标。

## 证据分级

- A：实测或样机数据；
- B：公开文献、标准或器件手册；
- C：公式、信号链约束、复杂度或物理模型推导；
- D：尚未验证的设计预期。

正文必须标明 D 级不是已实现效果。没有数值时，可以写条件性改善，例如“在增益切换期间避免未稳定样本进入正式结果”，不能编造百分比。

## 禁用写法

- “显著提升”“大幅改善”“完全解决”；
- “AI 使识别更准确”但不说明输入和硬件控制关系；
- 只比较产品价格或用户体验；
- 把未来可能实现的功能写成现有效果。

每项效果都应与交底书中的缺点编号对应。
