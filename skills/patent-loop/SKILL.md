# 单件专利推进循环

## 阶段

1. `intake`：技术问题、方案、效果、事实等级。
2. `research`：现有技术检索和对比文件账本。
3. `disclosure`：八章技术交底书。
4. `figures`：黑白专利附图和图号核对。
5. `claims`：装置/方法独立权利要求及从属项。
6. `review`：形式、支持、清楚性、效果和公开风险审查。
7. `export`：Word/PDF 导出和重新打开验证。

## 循环规则

- 每阶段先读取磁盘当前状态，不凭记忆判断完成。
- 当前阶段未通过时不跳级。
- 用户补充硬件或实现事实后，回读相关章节，更新问题、方案、效果和权项。
- 不把没有样机当成硬阻塞；只有关键技术关系无法实施或公开时才阻塞。
- 每次修改后记录：改了什么、为什么改、还有哪些事实待确认。

## 单件专利建议

一个主案可以包含多个创新点，但独立权利要求只保留不可拆分的主组合，其他创新放入从属权利要求或实施例。不要把互不依赖的功能硬塞入独权。
