# 专利附图设计

## 原则

- 黑白线条，不使用彩色背景、渐变或装饰图标。
- 一张图只表达一个结构、流程或状态关系。
- 总图先给系统边界，再给核心前端、方法流程和从属实施例。
- 图中不写“图1”或大标题，图号放在文档图注中。
- 中文标注优先；器件型号只在必要时出现。
- 同一部件全文使用同一名称和数字标号。

## 推荐图序

1. 系统总体结构；
2. 核心硬件/信号链；
3. 主方法流程；
4. 核心控制或调零流程；
5. 从属实施例或可选协同架构。

## 连线

- 数据流实线，控制流虚线；
- 每条判断必须有“是/否”两个明确出口；
- 箭头进入节点，不穿过节点文字；
- 同一对端点的多条关系应分组或拆图；
- 不能把“测量”直接连到输出而绕过有效许可门。

## 检查

- 正文引用和附图说明的图号一致；
- 图内逻辑与正文无矛盾；
- 渲染后无裁切、重叠或不可读小字；
- Word 内实际嵌入图片与源图一致；
- 图中不含与权利要求无关的营销文字。

使用 Graphviz、Mermaid、HTML 或 draw.io 均可，但必须保留可编辑源并输出 PNG/SVG。
