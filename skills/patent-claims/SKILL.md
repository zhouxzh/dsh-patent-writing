# 权利要求撰写

## 输入

先读取：

- 技术问题；
- 发明内容；
- 关键点；
- 具体实施例；
- 效果依据。

未读交底书不得凭记忆起草权项。

## 独立权利要求

1. 明确主题名称：装置、系统、方法或存储介质。
2. 前序部分写共有必要特征。
3. 特征部分写不可删除的区别组合。
4. 只使用结构、连接、步骤、参数关系等限定，不写宣传性效果。
5. 装置权项和方法权项分别覆盖相同发明构思。

## 从属权利要求

每条只增加一个限定方向，按重要性和具体程度排列。多项从属权利要求不得引用另一项多项从属权利要求。

## 一致性检查

- 每个权项特征在说明书中至少有一处完整支持；
- 术语与附图、实施例一致；
- 独立权利要求不依赖未说明的可选模块；
- 数值、材料、型号尽量放入从属项或实施例；
- 不引用附图编号作为必要限定。

## 输出格式

每条权项独立成段，连续编号，以句号结尾。除必要技术特征外，不加入“提高效率”“智能识别”等结果性空话。
